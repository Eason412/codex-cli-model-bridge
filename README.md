# Codex CLI Model Bridge

中文 | [English](README.en.md)

**在 Codex 里直接使用你的 Coding Plan 或订阅模型。** 本工具把 Codex 接到本机运行的 CLIProxyAPI（下称 CPA），让 Kimi、Gemini、DeepSeek 等模型和 GPT 出现在同一个模型选择器里，ChatGPT 登录、账号功能和历史任务都不受影响。新模型上线后自动出现，不需要改代码，也不用等本项目发新版。

Coding Plan 指 Kimi、智谱等厂商面向编程工具推出的订阅套餐；CPA 是一个在本机运行的开源代理服务，负责登录这些账号并转发请求。

当前开发版本：V0.0.5（未发布） · [更新日志](changelogs/V0.0.5.md)；已发布版本：[V0.0.4](https://github.com/Eason412/codex-cli-model-bridge/releases/tag/V0.0.4)。本项目基于 [Zhijian Skills 的 codex-cli-model-bridge](https://github.com/zjp1997720/zhijian-skills/tree/main/skills/codex-cli-model-bridge) 二次开发。

> **前提：需要先装好 CPA。** 本工具负责把 Codex 接到 CPA 上，不能替代 CPA。还没装也没关系，安装手册会先带你装好它。

## 为什么用它

- **新模型自动上架。** 模型列表直接取自 CPA。设好每天一次的定时同步后，CPA 一出现新模型，第二天就会出现在 Codex 的模型选择器里，不用改代码、写配置，也不用等本项目发版。
- **不丢登录，不丢历史。** 很多接入方式要把 Codex 的模型服务商切换成第三方，原来的历史任务会因此从列表里消失。本工具在 macOS 上保持服务商为 OpenAI，只把请求地址指向本机代理，所以 Codex 仍以 ChatGPT 账号登录，账号功能和历史任务都还在。
- **个性化设置只需一行。** 想隐藏某个模型、换默认推理强度，在一个小文件里写一行即可，还支持 `gpt-image-*` 这样的通配符。没写的设置保持 CPA 给出的默认值。
- **改动先校验，随时可回退。** 新生成的模型目录要先通过 Codex 自己的检查才会写入；修改 Codex 主配置前会先展示改动，确认后才写入。主配置和模型目录改动前都会自动备份，可以随时恢复。CPA 的密钥不会写进 Codex 配置，也不会出现在输出里。
- **真正跑通才算接入。** 验收时会让模型实际执行命令；只是出现在模型列表里，不算接入成功。

## 工作原理

```text
Codex ──► 本机透明代理 ──► CPA ──► 各家 Coding Plan 或订阅服务
          127.0.0.1:8318    127.0.0.1:8317
```

- **透明代理**：本工具安装的一个本机小服务。Codex 把请求发给它，它换上 CPA 的密钥后原样转给 CPA，不改请求内容。
- **CPA**：按模型名把请求送到对应的账号和服务商。
- **模型目录**：Codex 模型选择器读取的 JSON 文件。本工具从 CPA 取得最新的模型列表（包括上下文长度、推理档位等参数）生成它，再叠加你的个人设置。

日常请求只经过透明代理和 CPA；本工具的命令行只在安装、同步和检查时运行。macOS 默认用上面这种透明代理方式，桌面版和命令行都能用；Windows 默认另建一份独立的 Codex 配置，用 `codex --profile cli-proxy` 启动，不动主配置。

## 如何设置

交给你的 AI 助手来做。仓库里的 [SETUP.md](SETUP.md) 是写给 agent 的安装手册，Claude Code、Codex、Gemini CLI 等都能按它一步步执行，并在安装软件、修改配置、重启服务、消耗模型额度之前停下来征求你的同意。把下面这段话发给你的 agent：

> 克隆 https://github.com/Eason412/codex-cli-model-bridge ，阅读其中的 SETUP.md，按步骤帮我安装和配置。安装软件、修改配置、重启服务或消耗模型额度之前先问我。

整个过程大致是：确认 CPA 已经运行（没有就先装好）；从 CPA 取模型列表生成模型目录；让 Codex 通过本机透明代理连接 CPA；让一个模型真正执行一次命令作为验收；再按你的意愿设置每天自动同步。完成后重启 Codex，新模型就会出现在模型选择器里。

需要你亲自做的只有两件事：在 CPA 里登录你的 Coding Plan 或订阅账号（通常要在浏览器里操作）；在 macOS 上让 Codex 保持 ChatGPT 账号登录。uv、Node.js 等工具 agent 会检查，缺的话征得你同意后安装。

以后想调整，直接告诉 agent 就行。隐藏模型、换默认推理强度写进个人设置文件；想让所有模型统一用 500K 之类的上下文长度，在 Codex 配置里加一行即可（上下文用到 90% 时自动压缩）。写法见 [覆盖与补充模型](references/model-manifests.md)。

## 参与贡献

欢迎提交兼容修复、功能改进和文档修订。提交 PR 前请注意：

- 一个 PR 只解决一个问题，不夹带个人配置或无关的格式调整。
- 写清问题和最小复现、原因与解决思路，以及实际执行过的验证；没做的检查写明原因，不写成通过。
- 测试必须在临时的 HOME 和 CODEX_HOME 下运行，不读写真实配置，也不启停真实的 CPA 或代理。
- 涉及特定模型时，附上模型 ID、元数据来源、CPA 上游类型和去掉敏感信息的验证结果。
- 提交前检查 diff、日志和截图，去掉密钥、OAuth 数据、私人路径和内网地址。
- 仓库不内置任何模型 ID，个人偏好放在仓库之外。

完整要求见 [贡献指南](CONTRIBUTING.md)，创建 PR 时会自动带出模板。

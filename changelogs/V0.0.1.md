# V0.0.1 · 首个版本

发布日期：2026-09-10

面向 CLIProxyAPI（CPA）的 Codex 模型接入与配置维护 Skill。

## 功能

- 检查 Codex 配置、Provider、模型目录与 CPA 连接。
- 支持独立配置和桌面透明桥接，复用已有登录与上游路由。
- 支持内置及个人模型清单、启用清单、模型显示与上下文配置。
- 提供文本、Shell、多工具顺序、GPT Fast 和 V2 子代理任务传递探测。
- 配置修改支持预览、备份和幂等同步。

## 修复

- 子集同步保留未选中模型及顺序，避免 Astra 窗口被原生缓存覆盖。
- `--models` 优先于启用清单；禁止与 `--prune-managed` 混用。
- 回执报告全目录变化；回归测试使用真实清单解析。

## 验证与边界

- 43 项自动化测试通过。
- 需自行配置 CPA 与对应上游；本版本不附带账号、密钥或供应商插件。
- 合成 V2 探针不等于原生 spawn 验收；跨供应商压缩状态迁移尚未实现。

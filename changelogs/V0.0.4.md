# V0.0.4（未发布）

## 修复

- 回补透明代理的客户端 `Version` 头保底：保留显式 Codex 路径和默认 Homebrew 路径，默认路径不存在时回退到 PATH；保底默认 `0.160.0`，不降低更新客户端的版本头。
- 根配置预览仅显示受管字段，遗漏的凭据区块和原文注释不进入回执；有变更的 `configure-desktop`、`restore-default --apply` 要求匹配预览 SHA。
- 桌面配置与 runtime 不变且服务健康时，不写文件、不启动代理；runtime 更新单独报告前后 SHA。
- 空模型列表按已成功发现但必需路由缺失处理；普通探针精确比较标记并允许首尾空白。
- `sync --state-dir` 统一清单、启用集合、个人策略和归属状态的来源，显式策略优先。
- 原生缓存缺少旧模型或清单模板时，使用排序优先级最高的原生条目；模板回退记录在 `template_fallbacks`，不改清单数据。

## 清理

- 删除无行为的 `configure-multi-agent --brew`、`--skip-restart` 参数；旧调用需移除这些参数，命令仍不会重启服务。
- 删除 Homebrew 查找分支、未调用的等待函数、过时的 CPA 版本门槛和无人使用的 `evals/`。audit 仅报告 CPA 版本，兼容性依靠行为探针验证。
- 合并测试加载样板和字符串断言，隔离根配置 fixture，比较完整线程快照。
- Python 脚本声明 PEP 723，文档统一 uv 入口；Fast 和历史 Kimi 定制补丁分别集中到 reference，主 Skill 保留流程和边界。

## 验证与范围

- Python 3.11 隔离回归、Node HTTP 透传及版本头测试；语法、差异及文档本地链接检查。
- 本次仓库更新不部署运行副本，不重载 CPA 或透明代理，不修改真实配置与凭据，不发布 Release。
- 保留 Python 凭据助手的现有 YAML 解析、Ruby helper、隔离 profile、Windows/Router 文档、LaunchAgent label 和模型保护 ID。

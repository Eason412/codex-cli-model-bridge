# V0.0.5（未发布）

## 变更

- `sync` 改为从 CPA 拉取 Codex 格式的实时模型列表（带本机 Codex 版本号），整份生成模型目录，不再读取会过期的 `models_cache.json`。新模型随 CPA 升级进入列表，下一次同步即出现在 Codex，不需要改代码或写清单。
- 个人偏好改为 `overrides.json`：键为精确 ID 或通配符，只写与上游不同的字段，`null` 删除字段；未匹配的键只报告不阻断。
- `models.d` 只用于补充 Codex 格式列表里没有的路由；`template_slug` 改为可选，同名模型出现在实时列表后清单自动让位并在回执中列出。
- 桌面透明模式经 `openai_base_url` 同步，由代理补认证，不再需要隔离配置；目标目录默认取所用配置的 `model_catalog_json`。
- `audit` 新增 `in_sync_with_live_list`，目录落后于实时列表时报告。

## 安全条件

- 实时列表失败、为空或格式不对，个人偏好不合法，补充路由缺失，或结果会去掉配置使用的 `model`、`review_model`、`[agents].default_subagent_model` 时不写入。
- 内容不变不改文件；有变化时只保留一份 `<目录>.previous`，可每日无人值守运行。

## 移除

- 仓库内置的 7 个模型清单和 `policies/catalog.json`；仓库不再写任何模型 ID。
- `sync` 的 `--native-catalog`、`--catalog-policy`、`--models`、`--enabled-manifests`、`--adopt`、`--prune-managed`、`--skip-live-check`，以及 `supersedes` 字段和归属状态。

## 升级说明

- 旧的 `catalog-policy.json`、`enabled-manifests.json`、`state.json` 不再读取，回执的 `legacy_files_ignored` 会列出它们。原 `hidden_native_model_ids` 改写为 `overrides.json` 中的 `{"<id>": {"visibility": "hide"}}`。
- 已在实时列表中的模型，其 `models.d` 清单被忽略；仍需要的差异移到 `overrides.json`。
- 统一上下文大小改用 Codex 的 `model_context_window`。
